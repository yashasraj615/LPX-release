# LPX — Local Port eXplorer

See, understand and manage local services, ports and development stacks on Windows and macOS.
Local-first: no account, cloud or telemetry.

This public repository distributes installer assets and release information. Application source
is maintained privately. Download from [the latest release](https://github.com/yashasraj615/LPX-release/releases/latest).

| Platform | Version | Installer | Size | Architectures |
|---|---|---|---|---|
| Windows 10/11 | 1.1.0 | EXE | 5,944,690 bytes | x64 |
| macOS 11+ | 1.1.0 | DMG | 11,323,521 bytes | arm64, x86_64 |

Assets: LPX-Setup.exe, LPX.dmg, release.json and SHA256SUMS.txt. Binary assets live in GitHub
Releases, outside normal Git history. Checksums are provided for integrity verification.

Windows is unsigned. The Mac app is ad-hoc signed for local execution, without a Developer ID
signature or Apple notarization. See RELEASE_NOTES.md for tested behavior and installation notes.
